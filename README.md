# 海外项目数据集指标填报 · HTML 原型

依据《DSC-海外项目数据集指标填报-PRD-v1.0》与《需求规格说明书 V1.0》编制的高保真交互原型。
直接用 Chrome/Edge 打开 `index.html` 即可运行，无需构建。

## 文件结构

```
prototype/
├── index.html          # 页面骨架（顶栏 / 侧边栏 / 面包屑 / 模态框）
├── css/style.css       # DSC 设计体系 + 海外填报专属组件
└── js/
    ├── mock-data.js    # 数据层：14家单位×6数据集×六状态、字典、校验规则
    ├── views-task.js   # ZY-HY-TB-010 报送任务管理（列表/新建/进度看板/催办/关闭）
    ├── views-fill.js   # ZY-HY-TB-020/030 数据填报 + 四级校验（核心）
    ├── views-review.js # ZY-HY-TB-040 审核与退回（单位审核/局级复核/审计轨迹）
    ├── views-summary.js# ZY-HY-TB-050 汇总统计（率类重算/分供商去重/导出）
    ├── views-config.js # ZY-HY-TB-060 填报基础配置（指标/枚举/期间/单位/模板）
    └── app.js          # 路由、角色视角、计算引擎（口径权威定义）
```

## 演示场景（对照 PRD 验收标准）

- **A1 任务闭环**：任务列表 →「进度看板」查看 14 单位×6 数据集六状态矩阵；新建任务时选择已有期间可演示"重复创建阻断"；催办/关闭留痕。
- **A2 率类异常归零**：填报 D1/D2/D3 时计算字段实时置灰计算；局级复核人视角打开「西南公司 D3」（0 值记录）可见全部率类显示 `/`，替代线下 `#DIV/0!`。
- **A3 校验覆盖**：填报人 D5 点「提交」→ V-C03 查重失败清单定位到行；D4 明细含员工编号重复（V-C02）与电话格式错误（V-F03）案例；批量导入模态演示"先校验后入库 + 失败行导出"。
- **A4 去重自动化**：填报 D5 时重复行黄色高亮阻断、跨单位重复仅提示；汇总页 D5 名录按"名称+注册地"自动去重并保留各单关联。
- **A5 计算字段**：D1~D3 全部率类由 app.js 计算引擎按 SRS 口径实时计算，置灰不可编辑。
- **A6 汇总导出**：汇总页率类均为"汇总分子/分母重算"（非均值），覆盖率黄条标注；导出兼容现行表样。
- **A7 审核留痕**：退回必填原因；审核详情页含审计轨迹（操作人/时间/动作）。
- **A9 零报告**：填报页勾选「本期无数据」提交，计入齐套统计。
- **A10 口径可配置**：配置页指标字典"修改口径"支持选择生效期间，历史报表按当时口径复现。

## URL 深链接（演示直达）

`index.html?role=<角色>&page=<页面>&ds=<数据集/页签>&view=progress&unit=<单位>`

`page` 命中任一海外填报功能项即可直达（左侧菜单全量展示，与视角无关）；`role` 仅决定页面内的数据范围与操作权限。

示例：
- `?role=admin&page=task-manage&view=progress` — 进度看板
- `?role=filler&page=my-fill&ds=D2` — 填报 D2（可编辑，改数即实时重算）
- `?role=reviewer&page=review&unit=U07&ds=D3` — 西南公司 D3 全零记录复核（显示 `/`）
- `?role=admin&page=summary&ds=D5` — 分供商去重名录

> 原型数据为虚构演示数据，金额/数量口径参照现行线下报表量级编制。
