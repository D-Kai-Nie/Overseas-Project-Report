# 海外项目数据集指标填报 · HTML 原型

依据《DSC-海外项目数据集指标填报-PRD-**v1.1**》（双频 + 周月衔接）与 SRS V1.0 编制的交互原型。
直接用 Chrome/Edge 打开 `index.html` 即可运行，无需构建。

**V1.1 要点**：报送频率半年度 → **周报（每周五）+ 月报（每月底）双频**；新增 **周报数据集 W1~W6**（共享中心/区域总部/项目级填报）；新增 **ZY-HY-TB-070 周月数据衔接**（月报自动带出周报数据、来源标注、核对确认、覆盖留痕、一致性校验、缺失兜底）；催办改为截止前 1 天并支持逾期未报送原因登记。

**本轮优化（对照评审差异清单前四项）**

1. **W3/W6 字段补齐**：W3 集采跟踪表 14 → **21 列**（新增招采发起时间、预计完成时间、下周计划、采购编号、亮点、是否首次资源配置、备注）；W6 项目供应链风险全景表 10 → **24 列**（新增项目地址、物资设备采购总额、劳务分包采购总额、风险描述、预计损失、化解时间等），字段名与口径逐项对照 PRD 7.1，SC1/SC2/SC4 三套周报行数据同步补齐。
2. **一致性校验收敛到 W6 按单位真实汇总**：新增 `w6Baseline(uid)` —— 金额类项目行求和，率类按各项目采购总额**加权**（规则 18：禁止对率直接平均）；无已提交 W6 时返回空并走**缺失兜底**（转手工填报 + 汇总标注来源）。D1/D2/D3 一致性校验统一以该基准为准。
3. **校验扩展闭环**：新增 **V-C01** 唯一有效记录（主体+期间+数据集）、**V-G01~V-G06** 计算勾稽（导入携带的计算列原值与系统重算值比对，容差 ±1 元 / ±0.01 个百分点）、**V-G07** 金额类月报＜周报汇总**阻断**（可填差异说明留痕放行）、**V-G08** 率类偏差＞±5% **仅提示**；勾稽**尾差放行**闭环 ＝ 填报端申请留痕 → 局级复核书面确认（`varianceWaiver.confirmed`）→ 随记录归档，未确认可撤回；覆盖自动带出值须**权限 + 原因**，无权限尝试亦写入审计轨迹（`deniedOverrides`）。
4. **供货类型取自周报 W4**：D5 合格分供商名录 **13 项**由 W4 自动带出（原 12 项，新增「供货类型」＝W4「供应类型」），另填 3 项；PRD 7.2 的「15 = 12 + 3」相应修订为「**16 = 13 + 3**」。
5. **D2 同口径用量归属**：钢筋「同口径用量」按裁定改为**需填报字段**（原为系统自动算），系统改为按「实际用量 − 措施用量 − 临建用量」**口径核对并提示**（V-G04），不再改写填报值；D2 仍为 17 项（需填报 14、自动算 3）。

## 角色视角切换（顶栏右上 · 原型演示）

> **说明**：DSC 数字供应链系统**没有角色切换入口**，功能权限统一由**系统功能项授权**控制（如 ZY-HY-TB-010 报送任务管理、ZY-HY-TB-020 数据填报、ZY-HY-TB-070 周月衔接…）。

## 演示场景（对照 PRD 验收标准）

**双频与任务**
- **A1 任务闭环（双频）**：任务列表含周报/月报两类（频率列 + 筛选）；「进度看板」月报＝14 单位×D1~D6 矩阵，周报＝共享中心/区域总部×W1~W5 矩阵 + W6 二级单位附表；逾期主体可「登记未报送原因」；催办提示为截止前 1 天自动。
- **新建任务**：选择频率（周报=每周五 / 月报=每月底）后数据集范围自动切换 W1~W6 / D1~D6；选择已有期间可演示"同期间同频率重复创建阻断"。

**周月衔接（ZY-HY-TB-070，V1.1 核心）**
- **A11 自动带出**：填报人视角进入月报 D1，`物资设备集采引用金额` 置灰并标注"自动取自周报 W3（2026年9月第3周）"；D3 `调出资产原值金额` 取自 W5；D4 姓名/所在单位/职务/是否专职 取自 W2。
- **A12 覆盖留痕**：带出字段点「修改（覆盖留痕）」→ 必填修改原因 → 留痕提示，审计轨迹与复核详情页可查（操作人/时间/原值/原因）；**无权限覆盖**（非填报人本单位 / 非局报送管理员）按钮为「修改（无权限）」，点击即拒绝并写入审计轨迹。
- **A13 一致性校验（基准＝W6 按单位汇总）**：填报人视角进入月报 D1 点「提交」→
  ① `劳务与专业分包采购总金额` 月报值 200,600,000.00 元 ＜ 周报 W6 汇总值 203,000,000.00 元 → **V-G07 阻断**（填「差异说明」留痕后放行，留痕见审核页审计轨迹）；
  ② `物资设备采购总金额` 331,200,000.00 元 与 W6 汇总采购总额 305,000,000.00 元 偏差 +8.6% ＞ ±5% → **V-G08 提示核对**（不阻断）；
  ③ 率类由月报数据重算后与 W6 **按采购总额加权**的汇总率比对（U01 综合采购成本降低率 −19.5%、综合采购效益率 +5.9%，均 ＞ ±5%）→ **V-G08 提示**，率类不阻断；
  ④ 切换填报主体为「二公司 U03」可见**周报缺失兜底**：提示"未取到本期周报数据，转手工填报"，不作一致性校验亦不阻断。
- **A14 重复填报消除**：D5 名录 **13 项**标注带出（含「供货类型」取自 W4；无手工录入入口，仅补填优势劣势/总部地址/共享中心 3 项）；行编辑弹窗中带出字段为只读。
- **A15 周报链路**：填报页频率切至「周报」可填报 W1~W5（W1 数值区+工作总结区、W3 集采跟踪、W4 资源库含新增"资源所属国别/账期"、W5 调拨台账）；W6 页签为项目风险全景表；审核页「周报」页签走复核链路。
- **尾差放行闭环（差异清单第③项）**：填报页 D1「批量导入」→ 模拟导入（写入导入计算列）→ 点「提交」→ **V-G02 阻断**（导入携带值 7,500,000.00 元 vs 系统重算 7,500,002.40 元，偏差 2.40 元 ＞ ±1 元）→ 清单项「申请尾差放行」（差异原因必填，留痕）→ 提交放行 → 审核页 D1 复核时提示"申请尾差放行，待局级复核书面确认"，点「局级复核通过」即写入确认人与时间（`varianceWaiver.confirmed=true`）并随记录归档。
- **V-C01 唯一有效记录**：一公司 U02 月报 D1 已是「已通过」状态，再从填报页对同一「主体 + 期间 + 数据集」点提交 → **V-C01 阻断**（仅允许一条有效记录，更正须走退回或数据更正流程）。
- **D2 口径核对（V-G04）**：月报 D2 表单把钢筋「同口径用量」改为与（实际用量 − 措施用量 − 临建用量）不一致 → 提交时出现**口径核对提示**（仅提示、不改写填报值，节超量/节超率仍按填报的同口径用量计算）。
- **审计轨迹（复核详情页）**：汇总「覆盖自动带出值」「周月一致性差异说明」「勾稽尾差放行申请/确认」「无权限覆盖尝试」四类留痕（操作人/时间/原值/原因），周报与月报记录均可查。

**周报周度明细报表区（PRD 6.1 ② / 验收 A16）**
- **三个报表区**：汇总页页签按 PRD 6.1 分为「① 月度汇总区（D1~D6）」「② 周报周度明细区（W1~W6）」「③ 周月对比区」。
- **期次选择**：年度/月份 + 周次选择器（2026年9月第1~4周）；默认最近一个已提交周（第3周）；第4周未开始时提示待填报；历史周标记"已关闭"且只读（不回写，展示规则 24）。
- **六张明细报表**：W1 汇总表（跨主体合计行数值求和、率类按分子/分母重算，周工作总结等文本类逐条列示）；W2 人员配备（按共享中心/专职兼职筛选 + 小计）；W3 集采跟踪（按集采层级统计发起数/完成数/预计降本额/超期项数/首次资源配置项数 + 明细）；W4 分供商资源库（评级/资源所属国别/品类/可供应国别分布 + **联系人/电话/邮箱脱敏**）；W5 调拨台账（按调入组织汇总笔数与调入价格合计）；W6 风险全景（按二级单位统计高/中/低风险项目数与预计损失合计）。
- **月内周趋势**：在建项目数、集采完成个数、预计降本额、采购成本降低率（按各周分子/分母重算）的第1~3周对比（集采完成个数 25→31→37 递增），支撑月报核对与局例会通报。
- **覆盖范围标注**：当周未提交主体显著列示（如第3周 W1~W5 应报 5、已报 3，未提交：非洲共享中心、海外区域总部）。
- **导出**：单周导出（表样兼容现行周报 6 张表）与月内多周合并导出（带周次列），均提示留痕。
- **权限**：二级单位视角进入 W6 仅展示本单位明细（页面标注"按权限仅展示本单位明细"），局级可见全局。

**沿用 V1.0（继续有效）**
- **A2 率类异常归零**：局级复核人视角打开「西南公司 D3」（全零记录）可见全部率类显示 `/`；D2/D3 填报时率类实时置灰计算。
- **A3 校验覆盖**：D5 提交触发 V-C03 查重清单定位到行；D4 含员工编号重复（V-C02）与电话格式（V-F03）案例；批量导入模态演示"先校验后入库 + 失败行导出"。
- **A4 去重自动化**：D5 重复行黄色高亮阻断、跨单位重复仅提示；汇总 D5 按"名称+注册地"自动去重并保留各单关联。
- **A5/A6 计算与汇总**：全部率类由计算引擎按 SRS 口径实时计算；汇总页率类为"汇总分子/分母重算"（非均值）。
- **A9 零报告**：填报页勾选「本期无数据」提交，计入齐套统计。
- **A10 口径可配置**：配置页指标字典「填报方式三态」（需填报/系统自动算/自动取自周报），修改支持生效期间。
- **周月对比**：汇总页「周月」页签对比集采金额/成本降低额/分供商数/人员数的周报值与月报值，给出偏差与一致性结论，并标注数据来源（含周报缺失单位）。

## URL 深链接（演示直达）

`index.html?role=<角色>&page=<页面>&ds=<数据集/页签>&freq=<周报|月报>&subject=<填报主体>&unit=<单位>&task=<任务>&view=progress`

`page` 命中任一海外填报功能项即可直达（左侧菜单全量展示，与视角无关）；`role` 仅决定页面内的数据范围与操作权限。

示例：
- `?role=admin&page=task-manage&view=progress&task=T-2026W38` — 周报进度看板（共享中心×W1~W5 + W6 附表）
- `?role=filler&page=my-fill&ds=D1` — 月报 D1（海外公司 U01：带出字段 + 覆盖入口 + V-G07 阻断/V-G08 提示）
- `?role=filler&page=my-fill&ds=D1&subject=U03` — 二公司月报 D1（周报缺失兜底）
- `?role=filler&page=my-fill&freq=周报&ds=W3` — 周报 W3 集采跟踪表
- `?role=admin&page=summary&ds=CMP` — 周月对比（报表区③）
- `?role=admin&page=summary&ds=WK&wtab=W6` — 周报周度明细区·W6 风险全景（报表区②）
- `?role=admin&page=summary&ds=WK&week=T-2026W37&wtab=W1` — 指定期次（第2周）的 W1 汇总表
- `?role=filler&page=summary&ds=WK&wtab=W6` — 二级单位视角（仅见本单位 W6 明细）
- `?role=reviewer&page=review&unit=U07&ds=D3` — 西南公司 D3 全零记录复核（显示 `/`）

> 原型数据为虚构演示数据，金额/数量口径参照现行线下报表量级编制；周报取数默认口径为"当月最后一个已提交周报"（Q6 默认，可配置）。
